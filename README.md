# 🪔 Diwali 2026

A beautiful, interactive Diwali greeting and wishes web experience — spread the joy of the Festival of Lights! ✨

## ✨ About

**Diwali 2026** is a festive web page that lets users share heartfelt Diwali greetings with friends and family. Featuring stunning animations, vibrant visuals, and the warm spirit of Diwali.

## 🚀 Features

- 🎆 Beautiful Diwali-themed animations and visuals
- 🪔 Interactive greeting cards and wishes
- 📱 Fully responsive design — works on all devices
- 🔗 Easy sharing of personalized wishes
- ⚡ Lightweight and fast-loading

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Animations, gradients, and responsive layouts
- **JavaScript** — Interactivity and dynamic content

## 📦 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (e.g., VS Code) for development

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/easylauncherteam/diwali2026.git
   cd diwali2026
   ```

2. **Open in browser**

   Simply open `index.html` in your browser, or use a local dev server:

   ```bash
   # Using Python
   python3 -m http.server 8000

   # Using Node.js (npx)
   npx serve .
   ```

3. **Visit** `http://localhost:8000` in your browser
